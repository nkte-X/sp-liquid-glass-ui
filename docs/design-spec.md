# iOS Liquid Glass для Super Productivity: дизайн-спека

Цель: интерфейс Super Productivity в духе iOS 26 / macOS Tahoe Liquid Glass. Работает в светлой и тёмной теме, адаптирован под iPhone и iPad. Отдельного клиента нет: используются только встроенные возможности приложения.

| Инструмент | Как ставится | Роль |
|---|---|---|
| Плагин `plugin/` | Settings → Plugins → ZIP | Всё сразу: встроенная тема плюс поведение (см. его README) |
| Тема `themes/ios-liquid-glass.css` | Settings → Theme → Install theme | Необязательно: та же тема отдельным файлом, убирает вспышку при запуске |
| Штатные настройки | Settings | Primary color (рекомендуется `#007AFF`), dark/light/system, background image, отключение анимаций и tint |

## 1. Устройство темы

```
themes/src/base-liquid-glass.css   снимок встроенной темы upstream (не править)
themes/src/ios-layer.css           iOS 26-слой (править здесь)
themes/build.sh [--update]         сборка; --update подтягивает свежий upstream
themes/ios-liquid-glass.css        результат для установки
preview/ios-preview.html           макет мобильного DOM для подгонки (?dark=1, ?ios=0)
```

Снимок upstream: коммит `f6f97b31dc` (2026-10-30).

Правила:
- Светлая и тёмная тема переключаются только через `body.isDarkTheme`. `prefers-color-scheme` не используется, потому что у приложения своя настройка режима.
- Платформу определяем по классам приложения: `isIOS`, `isIPad`, `isNativeMobile`, `isTouchPrimary`, `hasMobileBottomNav`.
- Классы с префиксом `lgx-` зарезервированы за плагином, а токены темы называются `--lgx-*`.
- Собранная тема проходит штатный `validateThemeCss`: в ней нет `@import`, внешних `url()` и `data:`.

## 2. Материалы

Как и у Apple, стекло используется только для навигации и контролов. Контент остаётся почти непрозрачным.

| Уровень | Что | Материал |
|---|---|---|
| Контент | задачи, заметки, карточки, панели | непрозрачность 0.85–0.95 (upstream Tier A), без live blur |
| Chrome | tab bar, header action groups, кнопка «добавить» | `--lgx-glass-*`: tint, blur 22px, saturate 190%, блик сверху, тонкая обводка, мягкая тень |
| Overlay | меню, диалоги, sheets, snackbar | upstream Tier B: blur 50px, saturate 180%, яркий rim |
| Prominent | главное действие | стекло, тонированное `--lgx-tint`, нейтральная тень |

Где стекло запрещено (контент, не контролы; HIG «Liquid Glass», аудит `docs/liquid-glass-fixes.md`):

| Что | Чем вместо стекла |
|---|---|
| Строки задач и подзадач | Сплошная заливка темы |
| Строки панели деталей | Сплошные ячейки iOS inset-grouped (`--lgx-cell-bg`), один блок с волосками |
| Группы форм (экран настроек плагина) | Почти непрозрачные ячейки `#fff` / `#1c1c1e` (0.9), без blur и блика |
| Выбранный таб / пункт сайдбара / сегмент | Плоская заливка `--lgx-glass-lens`, без своей тени (иначе стекло на стекле) |
| Скрим под диалогом | Только затемнение, без blur |

Ограничения платформы:
- Преломления фона на iOS не будет: WKWebView не поддерживает `backdrop-filter: url(#svg)`. На desktop (Chromium) его можно добавить плагином.
- На iPhone одновременно держим не больше ~5 слоёв с blur. У строк списка blur нет никогда.
- У sticky текущей задачи непрозрачная заливка (upstream).

Радиусы — система, а не отдельные числа: внешние контейнеры заданы токенами, вложенные выводятся как «радиус контейнера − отступ» (аналог `ConcentricRectangle`). Других чисел в `border-radius` нет, кроме `0`, `999px` (капсулы) и `50%` (круги).

| Панель сайдбара (`--lgx-r-panel`) | 22 | 8 (`--lgx-pad-panel`) | пункт → 14 (`--lgx-r-nav-item`) |

| Sheet (`--lgx-r-sheet`) | 38 | 8 от краёв экрана | контент ≥ 14 от скругления |
| Диалог | 34 touch (`--lgx-r-alert`) / 26 desktop (`--lgx-r-dialog`) | — | кнопки-капсулы |
| Меню, autocomplete, snackbar (`--lgx-r-menu`) | 24 | — | пункты без радиуса |

Типографика (ориентир по шкале iOS): Large Title 34/700, Title2 22/700, Headline 17/600, Body 17, Subhead 15, Footnote 13, Caption 12/11. Пока применён только вес и трекинг заголовка страницы. Шрифт системный (SF), его подставляет базовый стек приложения.

## 5. Доступность

- `prefers-reduced-transparency`: непрозрачные заливки. Upstream снимает весь blur; наш слой в одном блоке в конце `ios-layer.css` делает сплошными все свои токены фона: `--lgx-glass-bg`, `--lgx-chrome-bg`, `--lgx-tabbar-bg`, `--lgx-compose-bg`, `--lgx-dialog-bg`, `--lgx-menu-bg`, `--lgx-row-bg(-hover)`, `--lgx-cell-bg(-hover)`, `--lgx-glass-lens`. Снимаются кольцо tab bar и инсет-блики сайдбара; sheet сплошной. Плагин: не включает пресеты стекла и Translucent, диалоги в iframe сплошные без blur; экран настроек — сплошные группы. Переключение подхватывается без перезапуска (подписка на `change` у `matchMedia`).
- `prefers-contrast: more`: обводка `1px var(--lgx-label-2)` у tab bar, кнопки «добавить», групп шапки, сайдбара, правой панели, compose-карточки, диалогов, меню / select / autocomplete, sheet; в настройках плагина — у групп, сегментного переключателя и кнопок. `--lgx-label-2` 0.8, `--lgx-separator` непрозрачный, стеклянные фоны плотнее на ~0.25. Акцент — high-contrast вариант.
- `prefers-reduced-motion` и `body.isDisableAnimations`: без spring-анимаций и масштабирования при нажатии.

## 6. Проверить на устройстве (Фаза 0)

1. Селекторы `.mobile-bottom-nav`, `.add-task-button`, `main-header .header-action-group`, `.page-title`, `.bottom-panel-sheet .drag-handle` в текущей сборке.
2. Кнопка «добавить» вынесена через `position: absolute`. Проверить, что ripple и long-press у слотов работают, а в режиме multi-select пустое место справа выглядит нормально.
3. Резерв снизу: тема задаёт `--bottom-nav-height: 62px`, приложение считает от него 62 + safe area + 8 = 104px. Этот резерв перенесён из `.main-content` в прокручиваемые области (страницы маршрутов и `work-view .today`). Проверить на остальных экранах (планировщик, расписание, доски, настройки), что последний элемент прокручивается выше бара. Multi-select bar и snackbar позиционируются от той же суммы.
7. Окно создания задачи: проверить с открытой клавиатурой, что список упоминаний (`#tag`, `+project`) не обрезается. У контейнера теперь есть `backdrop-filter`, а он меняет containing block для fixed-потомков.
4. Переключатели: размеры 51×31 требуют токенов отступа ручки (`--mat-switch-*-handle-horizontal-margin`) для Angular Material 22. Включить после проверки.
5. Работает ли `plugin.js` на iOS-сборке и есть ли `window.Capacitor?.Plugins?.Haptics`.
6. Отладка DOM: Safari → Develop → устройство. Если WebView не инспектируется, использовать диагностический плагин.

## 7. Чек-лист приёмки

- [ ] iPhone light / dark / system, с background image и без
- [ ] iPad: портрет и ландшафт, split view
- [ ] Reduce Transparency, Increase Contrast, Reduce Motion
- [ ] Reduce Transparency переключается без перезапуска
- [ ] Нет стекла в строках списков (задачи, детали, группы форм)
- [ ] Концентричность углов на Mac (панель сайдбара ↔ угол окна, пункты ↔ панель)
- [ ] Шапка на Mac: отступ сверху, ни одна кнопка не касается края окна
- [ ] Клавиатура и add-task bar, safe area в ландшафте
- [ ] Desktop Mac/Windows: тема не ломает upstream-вид (iOS-правила не срабатывают)
- [ ] Android: плавающий tab bar корректен (`hasMobileBottomNav` срабатывает и там)
